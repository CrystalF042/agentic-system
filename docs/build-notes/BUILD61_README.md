## 二、固定证据面板 `evidence.py`

五组共 25 格，跑出来 17 个有值、8 个**诚实留空并写明原因**：

```
【Valuation】     E/P、S/P、FCF/P        ← 新增，需要市值
【Quality】       毛利率/营业利润率/FCF margin/总负债率/流动比率/利息保障/ROE
【Growth】        营收同比、净利同比、分析师修正（长期为空，见下）
【Market】        波动率/下行波动/最大回撤/vs均线/尾随12-1/Beta/相关性/相对强弱/单日集中度
【Positioning】   分析师修正、机构持仓、事件反应
```

**估值组是新建的，不是搬运。** 它需要市值 = 股本 × 现价，而股本在
`dei:EntityCommonStockSharesOutstanding`（10-Q 封面页），**不在 us-gaap 里**——
只扫 us-gaap 会让估值组整组算不出来且没有任何报错。已加 dei 命名空间支持。

用收益率口径（E/P）不用市盈率：市盈率对亏损公司是负数或无穷大，无法排序；
E/P 对亏损公司自然为负，含义连续。

**几条刻意的诚实：**
- 分析师预期修正、机构持仓：免费源拿不到，**长期留空并写明原因**，不用别的东西凑
- 权益为负时 **ROE 不计算**——分母为负，盈利越多 ROE 越负，那个数字只会误导
- 口径说明与缺失原因是两个字段。混用会印出"总负债/总资产: 无数据（总负债，非有息债务）"，
  把口径当成了缺失理由（这个 bug 真的出现过，已修并加了回归测试）

## 三、真正的对抗式辩论 `debate.py`

```
Round 1   多空独立建案（互不可见 —— 防锚定）
   ↓
Round 2   交换后各自反驳对方最强三点
          且【必须回应面板上对自己最不利的三条】
   ↓
Judge     只做论证审计，不重做研究
   ↓
Synthesizer  一部观点
```

**我补了一个你的设计里没堵住的洞。** 固定 panel 挡住了"从 462 个里搜索"，
但挡不住**挑选行为从引用环节回来**：多头仍然只会援引对自己有利的那几格。
所以 Round 2 强制双方正面回应最不利的三条，且允许写"此点成立，我方承认"——
承认比硬辩有价值。Judge 再加一项：**审计双方共同回避了哪些证据**。
共同回避往往比双方争论的地方更值得看。

Judge 的提示词按你说的写死成 argument auditor：
「你不得引入任何新论点、新事实、新推测，也不要重新分析这家公司」。
输出是 `主张 | 提出方 | 证据 | 对方反驳 | 状态` 的审计表。

**成本**：Round 2 让 LLM 调用从 3 次变 6 次。`CIO_UA_REBUTTAL=0` 可关掉回到 3 次。
报告里会印出本次实际调用次数。

## 四、Invalidation 回路 `thesis_store.py` —— 这是我加的第五件事

你的设计里 invalidation conditions 是最值钱的一条，但**没有机制它就是装饰**。
写下"什么事实发生后 thesis 失效"很容易，没人回来查的话，
一部就是每天重新编一个故事、永远不会被证伪。

所以：

```
今日观点 → 失效条件落库（OPEN）
              ↓
此后每天：取出仍 OPEN 的条件，与当日新材料逐条比对
              ↓
命中 → 报告最顶部显示，连同触发它的那条材料与链接
```

命中**只提示不自动关闭**——是否真失效由你看材料决定，机器不替人下这个判断。

**为什么用确定性匹配而不是再叫一次 LLM**：让模型判断"我昨天写的失效条件是否已触发"，
等于给了它维护自己论点的裁量权，而它有很强的一致性偏好。
确定性匹配召回率不高，但**它不会替你把已经触发的说成没触发**——这个位置漏报远好过瞒报。

综合提示词里还硬性要求失效条件**必须可核对**：
「不许写成『基本面恶化』这类无法核对的模糊表述」，解析器也会把这类挡掉。
本轮没产出可核对失效条件时，报告会写：

> ⚠ 没有失效条件的论点此后无法被证伪。这本身值得注意。

### 一个中文分词的坑，值得单独说

第一版复检 **0 命中**，而且看起来完全正常——日志正常、流程正常、只是这个回路从来没工作过。

原因：中文没有空格，`[一-鿿]{2,}` 是贪婪匹配，抓的是标点之间的**整段短语**：

```
条件  "下季度数据中心营收同比转负"     → 一个 token
新闻  "…，数据中心营收同比转负，…"    → 另一个 token
```

两个字符串不相等，重合永远是 0。改成字符二元组后（"毛利率跌破" → 毛利/利率/率跌/跌破），
三条失效条件全部正确命中，无关新闻零误报。

**这是最危险的一类失败：不报错、看起来正常、信息没了。** 已加回归测试。

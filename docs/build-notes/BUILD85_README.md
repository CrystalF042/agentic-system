# build85 —— 盘前市场快照：期货 + 每个数字带自己的时间戳

## 一、新增 `src/cio/market_now.py`

期货、宏观、海外收盘各一组，全部免费源：

```
股指期货    ES=F  NQ=F  YM=F  RTY=F
宏观        ^VIX  ^TNX  DX-Y.NYB
海外市场    ^N225  ^HSI  ^STOXX50E
```

**核心不是"加了期货"，是每一行都带自己的 as-of 与实测年龄：**

```
标普500期货　5,712.25　-0.43%　[08-27 06:56]　实时
日经225　　　42,180.50　+0.88%　[08-27 02:00]　5.0 小时前
恒生指数　　 取数失败（RuntimeError）　⚠
```

## 二、新鲜度是【测】出来的，不是按品种假设的

最省事的写法是给符号打死标签："ES=F 是期货，标实时"。
但那样一来，**行情源挂掉、返回三天前陈数据时，它照样显示"实时"**——
标签来自类别，不来自数据。

所以 `classify_age()` 只做一件事：最后一根 K 线的时间戳减去当前市场时间，
按**实测年龄**归档。数据陈了标签自己会变，不需要任何人发现。

```
≤ 60 分钟   实时
≤ 6 小时    N 小时前
同一日历日   今日 HH:MM
昨天        昨日收盘 HH:MM
更早        N 天前  ⚠
时间戳在未来  时间戳异常（晚于当前）  ⚠     ← 时区搞错了必须看得见
```

这是个纯函数，不联网，所以能被完整测试。

## 三、取不到的行**保留**，不静默省略

省略一行的后果：报告上看不出这项缺失，读者以为"今天没什么可说的"，
而实际是数据源挂了。**这两件事在页面上必须能分辨。**

整段快照失败也不会拖垮简报——`build_premarket` 包了一层 try，
简报照常产出，只是少一节并在 `status.degraded` 里标注。

## 四、四分卡图例 —— 找到了你看不懂的原因

`C●●●●○ M●●●○○ Direct` 这套标记，图例在 **md 和 reportlab 里一直都有**，
唯独 **`render_html.py` 里没有**——而那正是实际生成你 PDF 的渲染器
（`run_premarket` 优先用它，reportlab 只是兜底）。

所以你收到的那份报告上印着这些符号，却没有任何一处解释它们是什么。
**这不是文档缺失，是第三个渲染器加进来时漏了一节**，
和 build62 那次 MD 改了、PDF 没跟上是同一类。

图例内容：

```
C1–5 来源可信度（5=一手来源）｜M1–5 事件重要性｜
Direct 直接命中关注池标的 · Sector 命中所属行业 · — 无关｜
Td 今日 · Wk 本周 · Med 中期 · Bg 背景。均为客观事实，非方向判断。
```

## 五、三个渲染器同时更新，并加了自检

`render_brief_md` / `render_brief_pdf`(reportlab) / `render_brief_html`(→PDF)
全部有快照节与图例，`check_build.py` 有一项专门守着这个——
**"忘了改另一个"从此会变红，而不是等你看 PDF 才发现。**

## 六、先验符号，再接进简报

```
python scripts/check_market_now.py
```

我这边的容器被 Yahoo 挡了（403），**无法验证这些符号真能取到数**。
这个脚本在你机器上跑，逐个符号打印价格、as-of、年龄标签。
取不到的直接从 `SYMBOLS` 里换掉——留在表里会让报告每天多一行"未取到"，
久了就没人看了。

**07:00 ET 跑的时候，预期是**：ES/NQ/YM 显示「实时」，
日经显示「今日 02:00 左右」，欧洲斯托克显示「实时」或「N 小时前」。
**如果期货显示"昨日"，那就是它真的不新鲜**——标签是算出来的，不是猜的。

# 一、v2 是被你那张表逼出来的，不是想出来的

2026-09-04 的基础率里有一个我上次没强调的数：

```
量比≥1.5      均值 9.3%   最低 2.8%   最高 21.7%     ← 差 8 倍
CMF>0.1&OBV↑  均值 19.1%  最低 10.4%  最高 29.1%
NR7           均值 21.5%  最低 15.7%  最高 30.5%
```

**同一条固定阈值的规则，在不同的日子会推 14 只或 109 只。** 这不是信号
强弱在变，是市场整体的波动水平在变——**而人的注意力预算是固定的。**

所以 v2 加的不是"更准的阈值"，是**分流**：

```
绝对闸门（v1 冻结的 A∧B∧C）   决定"今天有没有"  ← 安静的日子它说没有
横截面排名（score.py）        决定"有的时候先看谁" ← 忙的日子按序取前 K
```

## 为什么排名不能单独用

**任何一天都有人在前 5%。** 只用排名，系统永远说不出"今天没有"——
而那是你给 v1 定的第一条边界。所以闸门在前、排名在后，顺序不能反。
有一条探针钉住：没通过闸门的票必须没有排名，且 `today_line()` 要能输出"今天没有"。

## 分数里没有一个拟合出来的参数

```
score = 四个横截面分位数的等权平均

  participation   近20日放量天数
  accumulation    CMF20
  location        距上方价区的 ATR 距离（越近越靠前）
  relative        63日相对 SPY 超额   ← 闸门没用到这一维，排名用它补信息
```

**等权不是因为它最优，是因为我们没有任何东西可以用来定权重。** 定权重
要么靠远期收益（那就是在同一份历史上又拟合一次），要么靠拍脑袋（那就多
三个自由参数）。等权是唯一不引入新自由度的选择。有一条探针扫源码：
出现任何叫 `weight` 的赋值即红。

三个容易写错、写错了又不报错的地方各有一条用例钉着：

- **距离的方向**（越近分位越高）写反不会报错，只会让整套排名悄悄倒过来
- **并列取平均秩**，否则字母序会悄悄变成一个打分维度
- **缺的成分直接不算，不补 0、不补 0.5**——补 0 把"没数据"变成"很差"，
  补 0.5 变成"中性"，两个都是凭空造出来的结论

最后这条**变异测试第一次没抓到**：我原来断的是
`len(percentiles) == 4 - len(missing)`，而补 0 的实现让 `missing` 空、
`percentiles` 满 4 个，等式照样成立。改成断"location 必须在 missing 里、
且不在 percentiles 里"才红。

# 二、事件研究：能做，但先说它不能声称什么

```
.venv/bin/python scripts/technical_backtest.py --days 250
```

回放约一年，把冻结的 setup 每天重算一遍（`observe` 是纯函数、面板在缓存里，
只花 CPU），去重成事件，量 5/10/20 日相对 SPY 的超额、MFE/MAE，
并配**同日、同板块、相近波动档**的对照组。

## 三条硬约束，报告开头会先印出来

**一、幸存者偏差，方向向上。** 成分是今天的名单。标普500 一年约 20–25 只
变动，被剔除的多数是跌下去的。`survivorship_note()` 会报**可测的那一半**
（窗口内才有历史的票有几只），并明说被剔除的那些**数不出来**——
报一个下界，比假装没有偏差好得多。

**二、这不是样本外检验。** 阈值取自基础率表，而那张表来自同一段行情。
是同一份数据的另一种切法。

**三、样本按天聚集、窗口重叠。** 所以统计单位取**"日"而不是"事件"**：
每个有事件的日子算一个 (事件组均值 − 对照组均值)，再看这些日差。
这不能凭空造出独立性，但至少不假装每个事件都是独立样本。

**它的价值是证伪，不是证实。** 如果连在这种对自己最有利的条件下都看不出
任何东西，那就不用再往下做了。

## 对照组不匹配 setup 自己的成分

匹配同日、同板块、相近波动档——**不匹配"距上方价区的距离"和"放量天数"**。
匹配掉那两个，剩下的差异必然接近零，而那个零什么都不说明。
**同日匹配是四项里最重要的**：它按构造消掉了"那个月大盘在涨"这个混淆。

有一条探针走 AST 检查 `pick_controls` 的函数体：出现 setup 的任何一个成分即红。

## 结果不许回流——这条写成 import 约束，不是写成承诺

```
score.py / setups.py  不许 import backtest
```

一旦能 import，"根据回测结果调一下"就只差一行代码，而那一行不会有任何
东西拦住它。探针走 AST 检查两个文件的 import 表。
